# CPU 指令集架构（ISA, Instruction Set Architecture）

ISA(Instruction Seet Architecture，指令集架构) 是软件与硬件之间最核心的契约与接口

它决定了操作系统和编译器能向CPU发送什么指令，也规定了CPU硬件必须能够理解和执行哪些操作。ISA是连接上层软件生态与下层硬件电路的桥梁

ISA并不是具体的晶体管电路（微架构），而是一套规范和标准。它主要包含以下内容：

- 指令格式与操作码：CPU支持哪些指令（如加法`ADD`，跳转`JMP`，加载`LOAD`），以及这些指令在字节层面如何编码
- 寄存器规范：物理上暴露给软件的寄存器数量、类型和位宽（例如32位还是64位通用寄存器）
- 寻址模式：CPU如何根据指令算出数据在内存中的物理/虚拟地址
- 内存模型与一致性：软件如何访问内存，以及多核并发下内存读写顺序的规则
- 中断与异常处理：当发生硬件中断、除零错误或系统调用时，CPU的状态跳转机制
