# Operating System

操作系统是管理计算机硬件资源，并未应用程序提供运行环境的一类系统软件\
它是连接硬件和软件之间的中间层。没有操作系统，程序需要直接控制CPU、内存、硬盘、显卡、键盘等硬件；有了操作系统，程序只需要调用操作系统提供的接口

## 操作系统职责

### 1. 进程管理

CPU一次只能执行一个指令流，但电脑可以同时运行多个软件，操作系统通过进程调度让它们轮流使用CPU

### 2. 内存管理

程序需要内存

```c
int *p = malloc(1024);
```

但程序并不知道真实RAM地址，操作系统提供

```
程序看到的地址
0x00000000
v
虚拟内存
v
真实内存
RAM: 0x8F123000
```

作用：

- 隔离程序
- 防止互相破坏
- 支持多任务
- 支持虚拟内存

### 3. 文件系统

硬盘本质上只是大量存储单元，系统把它抽象为各种文件，负责

- 文件创建
- 删除
- 权限
- 目录结构
- 缓存

### 4. 设备管理

硬件种类非常多，每个设备都有不同接口，操作系统通过驱动统一管理

### 5. 网络管理

操作系统实现网络协议

如果没有OS，你需要自己

- 初始化CPU
- 管理内存
- 控制硬盘
- 写显卡驱动
- 写键盘驱动
- 写网络协议
- 管理多个程序

操作系统让你在不直接操作机器的情况下使用机器

# System Call

系统调用是操作系统内核为用户空间程序提供的一组服务接口\
它是应用程序与操作系统内核之间沟通的唯一合法渠道\
系统调用的集合，就是操作系统对外暴露的能力清单\

## 为什么需要系统调用

操作系统需要保护系统资源的安全性与稳定性。CPU引入了不同的特权级别（如x86架构上的Ring0与Ring3）

- 用户态(User Mode / Ring3)：普通应用程序运行的环境，权限受到限制，无法直接访问硬件（如硬盘、网卡）或操作敏感内存区域
- 内核态(Kernel Mdoe / Ring0)：操作系统内核运行的环境，拥有最高权限，可以直接操作硬件和管理整个系统的内存与进程

如果应用程序需要访问硬件资源（例如读取文件或发送网络数据包），它不能直接干预硬件，必须通过系统调用向内核发起请求，由内核代为完成操作后再将结果返回给应用程序

## 常见系统调用分类

不同的操作系统（如Linux, Windows, macOS）提供的系统调用接口有所不同，但基本覆盖以下几个核心功能（以POSIX/Linux为例）

| 分类 | 核心功能 | 典型系统调用 |
| - | - | - |
| 进程控制 | 创建、终止、调度进程 | `fork()`, `execve()`, `exit()`, `wait()` |
| 文件管理 | 创建、读取、写入、删除文件 | `open()`, `read()`, `write()`, `close()` |
| 设备管理 | 请求或释放外设资源，读取/写入设备 | `ioctl()`, `read()`, `write()` |
| 内存管理 | 分配与释放虚拟内存 | `brk()`, `mmap()`, `munmap()` |
| 网络与通信 | 建立网络连接、进程间通信(IPC) | `socket()`, `bind()`, `connect()`, `pipe()` |
| 信息维护 | 获取系统时间、进程PID等元数据 | `getpid()`, `time()`, `alarm()` |

## 系统调用的完整执行流程

当程序调用如`read()`这样的系统调用时，底层通常经历以下步骤

1. 发起请求：应用程序调用标准库（如C语言的`libc`）封装的接口
2. 设置参数与调用号：标准库将系统调用号(Syscall ID)及参数放入特定的CPU寄存器中
3. 陷入内核态(Trap)：执行一条特殊的硬件指令（如x86的`syscall`或`int 0x80`），触发软中断，CPU从用户态(Ring3)切换至内核态(Ring0)
4. 内核处理：内核根据系统调用号查阅系统调用表(Syscall Table)，找到对应的内核函数，校验参数合法性后执行具体操作
5. 返回结果：内核将执行结果存入指定寄存器，再次通过硬件指令将CPU恢复为用户态，程序继续向上执行

## 标准库函数和系统调用

在编程时很少直接编写汇编代码去触发系统调用，而是使用标准库函数

- 库函数：运行在用户态，封装了具体的逻辑。有些库函数完全在用户态完成；有些库函数内部会封装一个或多个系统调用
- 缓冲与优化：像`printf`或`fwrite`带有用户空间缓冲区，只有在缓冲区满了或遇到刷新条件时才会触发一次`write`系统调用，以此降低频繁切换内核态带来的上下文切换开销
