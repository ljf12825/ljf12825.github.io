应用层是直接面向应用程序提供网络服务的层级，它主要包括应用程序使用的各种网络协议

| 类型 | 协议 | 用途 |
| - | - | - |
| Web | HTTP/HTTPS | 网页，Web API |
| 域名 | DNS | 域名 -> IP |
| 文件传输 | FTP / TFTP | 文件传输 |
| 邮件 | SMTP / POP3 / IMAP | 邮件收发 |
| 远程登录 | SSH | 远程终端 |
| 远程登录 | Telnet | 远程终端 |
| 配置 / 管理 | DHCP | 自动获取IP等网络配置 |
| 时间 | NTP | 时间同步 |
| 网络管理 | SNMP | 管理网络设备 |
| 实时通信 | WebSocket | 长连接双向通信 |
| 游戏 / 自定义 | 自定义 TCP / UDP 协议 | 游戏服务器、RPC等 |
